# review-comment-ext（Staging Review Comments）

ステージングサイト上の要素を選んでコメントを付けられる、レビュー用の Chrome 拡張機能（Manifest V3）。
新規ページ作成やWeb運用で、ステージング画面をレビューするときに使う。

## インストール（初回・場所を変えたとき）

1. Chrome で `chrome://extensions` を開く。
2. 右上の「デベロッパーモード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダ（`~/develop/review-comment-ext/`）を選ぶ。
4. ツールバーのアイコンをクリックすると、右側にサイドパネルが開く。

## アップデートしたとき

1. このフォルダのファイルを書き換え、`manifest.json` の `version` を上げる。
2. `chrome://extensions` でこの拡張の「再読み込み」ボタン（↻）を押す。
3. 開いているページは再読み込みする（content script を入れ直すため）。

## 使い方

- 「あなたの名前」を入れ、「＋ 要素を選んでコメント」→ ページ上の要素をクリック → コメントを書いて保存。
- コメントは `chrome.storage.local` に保存される（ブラウザ内のみ。他の人とは共有されない）。
- 「Markdownでコピー」でレビュー結果を貼り付けられる。「JSON保存」でファイルに書き出せる。

## 注意

- 読み込んだフォルダの場所を変えると拡張機能のIDが変わり、それまでのコメントが見えなくなる。場所を変える前に「JSON保存」で書き出しておく。
- `host_permissions` が `<all_urls>` のため、レビューしないときは `chrome://extensions` でオフにしておくとよい。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張機能の設定 |
| `background.js` | アイコンクリックでサイドパネルを開く |
| `content.js` | ページ上の要素選択・ハイライト・ピン表示 |
| `sidepanel.html` / `.css` / `.js` | コメントの入力・一覧・書き出し |
