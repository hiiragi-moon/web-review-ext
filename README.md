# web-review-ext（Staging Review Comments）

ステージングサイトを見ながら、気になる場所（要素や文字）を選んでコメントを付けられる Chrome 拡張機能（Manifest V3）です。
付けたコメントは、修正箇所の一覧としてPDFやJSONで書き出せます。
新規ページ作成やWeb運用で、ステージング画面をレビューするときに使います。

リポジトリ: https://github.com/hiiragi-moon/web-review-ext

前半（1〜8）はレビューをする人向けの使い方、後半は開発・メンテナンス用のメモです。
版ごとの変更点は [`CHANGELOG.md`](CHANGELOG.md)（リリースノート）を見てください。

---

## 1. 導入する（最初の1回だけ）

1. この拡張機能のフォルダを手元に用意する。
   - `git clone https://github.com/hiiragi-moon/web-review-ext.git`
   - または GitHub の「Code」→「Download ZIP」でダウンロードして展開する。
2. Chrome で `chrome://extensions` を開く。
3. 右上の「デベロッパーモード」をオンにする。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、用意したフォルダを選ぶ。
5. ツールバーのパズルのアイコンから、青い「R」のアイコンをピン留めしておくと便利です。

> フォルダは読み込んだ場所から動かさないでください。場所を変えると拡張機能のIDが変わり、それまでのコメントが見えなくなります。場所を変える前に「JSON出力」で書き出しておいてください。

---

## 2. コメントを付ける

1. レビューするページを開き、ツールバーの「R」アイコンを押す。右側にサイドパネルが開きます。
2. いちばん上の「レビュワーネーム」に自分の名前を入れる（一度入れれば次回も残ります）。
3. 「＋ 要素・文字を選んでコメント」を押す（ショートカット **Option+C**、Windows は **Alt+C**）。
   - サイドパネルが閉じていても、ショートカットで開いて選択を始めます。もう一度押すと中止します。
   - キーは `chrome://extensions/shortcuts` で変更できます。
4. ページ上で対象を選ぶ。
   - **クリック**：段落・画像・ボタン・枠（div）など、要素全体が対象になります。画像以外の要素は、選んだときの見た目を撮影して対象欄に表示します（画面に見えている部分だけ）。
   - **↑ / ↓ キー**：クリックするとマウスの下のいちばん内側の要素（文字の段落など）が選ばれます。外側の枠（div など）を選びたいときは、青い枠が出ている状態で **↑** を押すと1つ外側へ広がり、**↓** で戻ります。
   - **ドラッグ**：なぞった文字だけが対象になります。
   - 先に文字を選んでから「＋」（またはショートカット）を押すと、その文字がそのまま対象になり、すぐコメント欄が出ます（パネルを押したときにページ上の選択が消えても、直前に選んだ文字を使います）。
   - やめるときは **Esc** か、もう一度ボタンを押します。
5. サイドパネルにコメント欄が出るので、内容を書いて「保存」（⌘+Enter でも保存）。

- 対象を選んだ時点でコメントは保存され、入力した内容も自動で保存されます。「保存」を押し忘れて次の対象を選んだり、パネルを閉じたりしても消えません（未入力のままなら「(コメント未入力)」として一覧に残ります）。
- 「キャンセル」を押すと、選んだ対象ごとコメントを取り消します。

iframe内の要素・文字も同じ操作で選べます（別ドメイン・入れ子のiframeも対象）。コメントは、iframeを表示している親ページの一覧にまとまります。

保存すると、ページ上の対象に番号のピンが付きます（文字の場合は黄色いマーカーも付きます）。
ピンはサイドパネルを開いている間だけ表示されます。
文字コメントは、あとで文言が少し変わっても前後の文脈から位置を探し直します。

## 3. コメントを管理する

サイドパネルの一覧で、次の操作ができます。

| やりたいこと | 操作 |
|---|---|
| 対象の場所を確認する | 一覧の項目をクリック（ページがその場所までスクロールして光ります） |
| コメントを直す | 「編集」→ 直して「保存」（入力は自動で保存されます。⌘+Enter で保存して閉じる、Esc・「キャンセル」で編集前に戻す） |
| 修正済みにする | 「解決」（番号の丸が緑になります） |
| どう直したかを残す | 解決済みの項目で「解決コメント」（一覧・JSON・PDFに出ます） |
| 未解決に戻す | 「再開」 |
| 消す | 「削除」 |
| このページのコメントをすべて消す | 「解決済みも表示」の行の右にある「全削除」（解決済みも含めて消えます。元に戻せないので、必要なら先に「JSON出力」） |
| 番号の順番を変える | 項目を左の ⋮⋮ でドラッグして、青い線が光る位置で離す（番号が振り直されます） |
| 解決済みも見る | 「解決済みも表示」にチェック |

- 解決済みのコメントは本文を編集できません。直したいときは「再開」してから編集します。
- ドラッグ中、一覧の端に近づくと自動でスクロールします。一番上・一番下にも入れられます。
- 右上の「未解決 3 / 5」は、未解決の件数 / 全体の件数です。
- 長い文字を対象にした場合は省略せずに表示します。対象欄の中をスクロールして読めます。

## 3-2. コメントしたページの一覧（管理画面）

サイドパネル右上の「☰ ページ一覧」を押すと、管理画面が新しいタブで開きます（`chrome://extensions` のこの拡張の「詳細」→「拡張機能のオプション」からも開けます）。

- 左上の「← 元のページに戻る」で、管理画面を開く前に見ていたタブに戻ります（管理画面のタブは閉じます）。
- コメントしたページが、最後に更新した順に並びます。ページごとに「未解決 / 全件」が出ます。
- ページの行をクリックすると、そのページのコメントが開きます。
- 「ページを開く」「JSON出力」「削除」（そのページのコメントをすべて削除）ができます。「ページを開く」は、そのページをすでにタブで開いていれば、そのタブに切り替えます。
- 上の入力欄で、タイトル・URL・コメントの内容から絞り込めます。「未解決があるページだけ」で未対応のページだけにできます。
- 「すべてJSON出力」で、全ページのコメントを1つのファイルに書き出せます（バックアップにも使えます）。
- 右上に、コメントの件数と保存容量の使用量が出ます。

## 4. 下に表示する（画面が狭いとき）

サイドパネル右上の「⬇ 下に表示」を押すと、サイドパネルが閉じて、ページの下部に同じ画面（下パネル）が出ます。

- 左に操作、右にコメントが横に並びます。
- 上端のバーをドラッグすると高さを、左右の境目をドラッグすると左側の幅を変えられます（どちらも次回も使われます）。
- 高さを小さくして左の操作欄が収まらないときは、操作欄をスクロールできます。
- 設定済みのショートカットは下パネルの選択ボタンにも表示されます。
- 「➡ 横に戻す」でサイドパネルに戻り、「✕ 閉じる」で閉じます。
- 下パネルはそのタブだけに出ます。ページを再読み込みしても出たままです。PDF出力の撮影には写りません。

## 5. レビュー結果を出力する

一覧の下の「レビュー結果を出力」から書き出します。

### PDF出力
1. 「PDF出力」を押す。ページが自動でスクロールし、上から順に撮影します（撮影中はタブを切り替えないでください）。
2. 撮影が終わるとレポートのタブが開き、1ページのPDFが自動でダウンロードされます。

- ページ全体のスクリーンショット（番号のピンと印付き）と、修正箇所の一覧が1枚にまとまります。
- 2枚目以降は固定ヘッダーなどを一時的に隠して撮ります（同じヘッダーが何度も写らないように）。
- レポート画面上部の「修正箇所を 横に／下に」で配置を変えられます。変えたら「PDFをダウンロード」を押し直してください（選んだ配置は次回も使われます）。
  - **横に**：図の右側で、各修正箇所が対象と同じ高さに並びます（重なる場合は下へずらします）。
  - **下に**：図をページ幅いっぱいに置き、その下に修正箇所を番号順に3列で並べます。
- PDFを作る一瞬、画面上部に「デバッグを開始しました」という帯が出ますが、すぐ消えます（Chrome のPDF作成機能を使うため）。
- 「解決済みも表示」にチェックが入っていると、解決済みもPDFに含まれます。

### JSON出力
「JSON出力」を押すと、表示中のページのコメントがJSONファイルでダウンロードされます。
要素を撮影した対象は、`targetImage` に画像のデータ（data URL）が入ります。
iframe内の対象には、親から順にiframeを特定するセレクタの配列 `framePath` が入ります。親ページの対象は空配列です。
コメントの内容をほかのツールに渡したいときに使います。

## 6. 知っておいてほしいこと

- **コメントは自分のブラウザの中にだけ保存されます**（`chrome.storage.local`）。他の人とは自動で共有されません。結果を共有するときはPDFかJSONを書き出して渡してください。
- コメントはページ（URL）ごとに分かれています。同じページを開くと、前に付けたコメントが出てきます。
- ホバーで出るメニューなど、撮影のときに見えていない部分は、PDFの図に印が付きません（一覧には注記が出ます）。
- iframeのPDF出力では、フレーム内で現在表示されている範囲を撮影します。フレーム内部を自動スクロールして全体を撮影することはありません。
- Chromeが拡張機能の実行を許可しないフレーム内では使えません。iframeの構造や識別用の属性が変わると、保存済みの対象を見つけられなくなる場合があります。
- 回転・傾斜のCSS変形があるiframeでは、撮影位置が正確に一致しない場合があります。
- ページの中の別の枠でスクロールする作りのページは、PDFでページ全体を撮れないことがあります。
- サイトによっては「下に表示」の中身が出ないことがあります。そのときはサイドパネルで使ってください。
- `host_permissions` が `<all_urls>` のため、使わないときは `chrome://extensions` でオフにしておくと安心です。

## 7. うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「ページを再読み込みしてから…」と出る | ページを再読み込みしてから、もう一度試す |
| ボタンにショートカット（⌥+C）が出ていない | `chrome://extensions/shortcuts` で「要素・文字を選んでコメント」にキーを設定する |
| ピンが出ない | サイドパネル（または下パネル）を開いているか確認する |
| PDFが作れない | レポート画面の「印刷画面で保存」から保存する |

---

## 8. アップデートしたとき

`git pull` するか、新しいフォルダの中身に入れ替えたら、`chrome://extensions` でこの拡張の「再読み込み」（↻）を押し、開いているページも再読み込みしてください。
同じフォルダの場所のまま中身を入れ替えれば、これまでのコメントは残ります。

## 開発・メンテナンス

### 変更を反映する

1. このフォルダのファイルを書き換え、`manifest.json` の `version` を上げ、`CHANGELOG.md` に変更点を書く。
2. `chrome://extensions` でこの拡張の「再読み込み」ボタン（↻）を押す。
3. 開いているページは再読み込みする（content script を入れ直すため）。

### 設計メモ

- Chrome のサイドパネルそのものは下に移動できない・最低幅も変えられない（Chrome の仕様）ため、「下に表示」はページ内に下パネルを差し込む方式にしている。

### ファイル構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張機能の設定 |
| `background.js` | アイコンクリックでサイドパネルを開く |
| `frames.js` | iframeの所属・親ページ座標の取得 |
| `content.js` | ページ上の要素選択・ハイライト・ピン表示 |
| `sidepanel.html` / `.css` / `.js` | コメントの入力・一覧・書き出し・PDF用の撮影 |
| `report.html` / `.css` / `.js` | PDF出力用のレポート画面（印刷してPDFに保存） |
| `manage.html` / `.css` / `.js` | 管理画面（コメントしたページの一覧。拡張機能のオプションページ） |
| `CHANGELOG.md` | リリースノート（版ごとの変更点） |
| `icons/` | 拡張機能のアイコン（青地に白の「R」。16/32/48/128px） |


### テスト

開発用のNode.js依存パッケージは、Chrome拡張機能の利用時には不要です。
Node.js 24以上で `npm ci` → `npm test` → `npm run check` を実行します。
DOM回帰テストでは、別オリジン・入れ子の選択、文字選択、フレーム別ピン、撮影座標、PDF、全フレームの選択終了を確認しています。

Chrome実機での確認用ページ:

1. このフォルダで `python3 -m http.server 8765` を起動。
2. `http://localhost:8765/tests/fixtures/index.html` を開く。
3. 拡張機能を再読み込みし、ページも再読み込みする。
4. 同一オリジン・別オリジン・入れ子・sandboxの各フレームで、要素クリックと文字ドラッグを確認する。
5. 選択確定・Escの後に他のフレームで通常操作に戻ること、下部パネルが1つだけ表示されることを確認する。
6. ページを再読み込みしてピンが同じフレームに復元され、一覧をクリックすると親のiframeと内部の対象が表示されることを確認する。
7. 画面下部のフレームにもコメントを付け、PDF・JSONに含まれること、拡大縮小のあるフレームの対象画像が正しい位置から切り出されることを確認する。

jsdomはChromeの拡張機能API・フレーム分離を再現しきれないため、Chrome実機での確認も必要です。
