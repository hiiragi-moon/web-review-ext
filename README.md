# review-comment-ext（Staging Review Comments）

ステージングサイト上の要素を選んでコメントを付けられる、レビュー用の Chrome 拡張機能（Manifest V3）。
新規ページ作成やWeb運用で、ステージング画面をレビューするときに使う。

## インストール（初回・場所を変えたとき）

1. Chrome で `chrome://extensions` を開く。
2. 右上の「デベロッパーモード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダ（`~/develop/review-comment-ext/`）を選ぶ。
4. ツールバーのアイコンをクリックすると、右側にサイドパネルが開く。

## アップデートしたとき

1. このフォルダのファイルを書き換え、`manifest.json` の `version` を上げる。
2. `chrome://extensions` でこの拡張の「再読み込み」ボタン（↻）を押す。
3. 開いているページは再読み込みする（content script を入れ直すため）。

## 使い方

- 「レビュワーネーム」を入れ、「＋ 要素・文字を選んでコメント」を押してから、ページ上で対象を選ぶ → コメントを書いて保存。
  - **クリック**：要素（段落・画像など）全体が対象になる。
  - **ドラッグ**：選んだ文字だけが対象になる。保存後は黄色のマーカーで表示される。
  - 「＋」を押す前に選択していた文字は対象にならない（押すと選択が解除される）。
  - 選ぶのをやめるときは、Esc キーか、もう一度ボタンを押す。
  - ショートカット **Option+C**（Windows は Alt+C）でもボタンを押したのと同じになる。サイドパネルが閉じていれば開いて選択を始める。もう一度押すと中止。キーは `chrome://extensions/shortcuts` で変更できる。
  - 文字コメントは、あとで文言が少し変わっても前後の文脈から位置を探し直す。
- **下に表示**：サイドパネル右上の「⬇ 下に表示」で、サイドパネルを閉じてページ下部に同じ画面（下パネル）を出す。
  - 左に操作、右にレビュー項目が横に並ぶ。上端のバーをドラッグすると高さを、左右の境目をドラッグすると左側の幅を変えられる（どちらも次回も使われる）。
  - 「➡ 横に戻す」でサイドパネルに戻り、「✕ 閉じる」で下パネルを閉じる。
  - 下パネルはそのタブだけに出る。ページを再読み込みしても出たまま。PDF出力の撮影には写らない。
  - Chrome のサイドパネルそのものは下に移動できない・最低幅も変えられない（Chrome の仕様）ため、この方式にしている。
- コメントは `chrome.storage.local` に保存される（ブラウザ内のみ。他の人とは共有されない）。
- 一覧の「編集」で、保存したコメントの本文を直せる（⌘+Enter で保存、Esc で取り消し）。解決済みのコメントは本文を編集できず、代わりに「解決コメント」（どう直したか など）を書ける。解決コメントは一覧・JSON・PDFに出る。
- 一覧の項目をドラッグ（左の ⋮⋮ が目印）すると並べ替えられ、レビュー番号が振り直される。落とす位置に青い線が光る。一番上・一番下にも入れられ、一覧の端に近づくと自動でスクロールする。
- 一覧の下の「レビュー結果を出力」から書き出す。
  - **JSON出力**：表示中のページのコメントをJSONファイルで保存する。
  - **PDF出力**：ページ全体のスクリーンショット（番号のピンと印付き）と修正箇所の一覧を並べた、1ページのレポートを作る。
    - 押すとページが自動でスクロールし、上から順に撮影して1枚に貼り合わせる。撮影中はタブを切り替えない。
    - 2枚目以降は固定ヘッダーなどを一時的に隠して撮る（同じヘッダーが何度も写らないように）。
    - 撮影が終わるとレポートのタブが開き、1ページのPDFが自動でダウンロードされる。
    - 修正箇所の配置は、レポート画面上部の「修正箇所を 横に／下に」で切り替えられる（切り替えたら「PDFをダウンロード」を押し直す。選んだ配置は次回も使われる）。
      - **横に**：図の右側で、各修正箇所を対象と同じ高さに置く（重なる場合は下へずらす）。
      - **下に**：図をページ幅いっぱいに置き、その下に修正箇所を番号順に3列で並べる。
    - PDFを作る一瞬、画面上部に「デバッグを開始しました」という帯が出る（Chrome のPDF作成機能を使うため。すぐ消える）。
    - 「解決済みも表示」のチェックが入っていれば解決済みも含める。
    - ホバーで出る要素など、撮影時に見えていない対象は図に印が付かない（一覧に注記が出る）。
    - ページ内の別の枠でスクロールする作りのページは、全体を撮れないことがある。

## 注意

- 読み込んだフォルダの場所を変えると拡張機能のIDが変わり、それまでのコメントが見えなくなる。場所を変える前に「JSON保存」で書き出しておく。
- `host_permissions` が `<all_urls>` のため、レビューしないときは `chrome://extensions` でオフにしておくとよい。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張機能の設定 |
| `background.js` | アイコンクリックでサイドパネルを開く |
| `content.js` | ページ上の要素選択・ハイライト・ピン表示 |
| `sidepanel.html` / `.css` / `.js` | コメントの入力・一覧・書き出し・PDF用の撮影 |
| `report.html` / `.css` / `.js` | PDF出力用のレポート画面（印刷してPDFに保存） |
| `icons/` | 拡張機能のアイコン（青地に白の「R」。16/32/48/128px） |
