# iframe対応

通常の選択操作で同一・別オリジン・入れ子のフレーム内の要素と文字を扱う。
コメントは親ページのURLに保存し、親からのiframeセレクタ列 `framePath` で対象を区別する。
既存のコメントは `framePath: []` と同じ扱いにする。追加権限は不要。

実装手順（このセッションで実施）:
1. DOMを使う回帰テストを追加し、iframe内の選択が失敗することを確認する。
2. `frames.js` で親子間の位置・セレクタ情報を取得する。ページからのメッセージは位置情報の問い合わせだけに限定し、拡張機能の操作は受け付けない。
3. 全フレームにcontent scriptを配布。選択終了は全体に伝え、コメントは所属フレームだけで表示。下パネルと撮影の制御は親のみ。
4. 子フレームの撮影対象をbackground経由で集め、PDFに座標変換して渡す。iframe内は現在表示されている領域を対象にする。
5. 全テスト・構文チェックを実行。導入方法と制限をREADMEとCHANGELOGに記載する。

確認する条件: 同一セレクタが複数フレームにある場合、入れ子、枠線・拡大縮小・画面外、再読み込み後の復元、遅れて読み込まれるフレーム、既存の親ページコメント。
ブラウザがcontent scriptの実行を許さないフレームは対象外。回転・傾斜変形の撮影座標は対象外。
